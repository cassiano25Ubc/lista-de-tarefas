# 📝 Minha Lista de Tarefas (To-Do List)

Aplicação web simples, moderna e responsiva de gerenciamento de tarefas do dia a dia, desenvolvida com tecnologias web fundamentais para organizar a rotina de forma prática.

---

Você pode testar a aplicação diretamente no seu navegador através do link abaixo:

 * Testar o Projeto no Navegador: file:///c%3A/JS%20projeto/assets/index.html

---

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando:
* **HTML5**: Estruturação semântica da página.
* **CSS3**: Estilização moderna, variáveis customizadas, responsividade e flexbox/grid.
* **JavaScript (ES6+)**: Manipulação do DOM, gerenciamento de estado local e interatividade da aplicação.

---

## ✨ Funcionalidades

* **Adicionar Tarefas**: Insira novas tarefas facilmente através de um campo de texto interativo.
* **Marcar como Concluída**: Conclua itens da lista com feedback visual imediato (texto taxado e alteração de opacidade).
* **Remover Tarefas**: Exclua itens individualmente com um botão dedicado.
* **Estado Vazio Dinâmico**: Mensagem informativa exibida quando não há tarefas pendentes.
* **Design Responsivo**: Adaptado perfeitamente para dispositivos móveis e computadores.
