 projeto: TO-do list simpoles com html, css e javascript

 este será um projet de tela única , em que na parte superior teremos um campo de texto para adicionar uma tarefa nova e um botão de envio.

 ao enviar a tarefa, ela será adicionada a uma lista exibida logo abaixo desse campo de texto.

 as tarefas serão armazenadas em um array no própio javascript, sem uso de nennhuma ferramenta ou sistema externo.

 cada tarefa;
 -texto
 - boolean confirmado se está feita ou 

 sobre as ações  possíveis em cada tarefa:
 - marcar/desmarcar ela como concluída, daí o texto fica riscado( via classe css).
 _ deletar uma tarefa, então ela some da lista completamente.
 - adicionar uma tarefa nova através do campo de texto na parte superior da tela , que será sempre adicxionada com o boolen de confirmação em false.

 o projeto será feito utilizando HTML,CSS e javascript simples .

 no javascript, trabalhar sempre com eventlisteners e não adicionando eventos no html diretamente .
 no início do javascript, jaá selecione em variáveis todos os elementos que serão manipulados.

 interface gráfica :

- o fundo do projeto será um azul claro.
- tanto o campo quanto a lista ficarão em cards separados , com fundo branco, borda arredondada e uma leve separação entre os cards.

a cor predominante para os botões( como o botão de adcionare deletar) será azul escuro.
